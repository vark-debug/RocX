⚡ 关键数据流示例:提交一次生成
1
WebView · PromptInput.vue
用户点 @submit → 触发 submitApi.submitGenerate()
2
WebView · useSubmit.ts
resolveSubmitOwner (优先 useCaptureContext,否则 bridge.queryProjectState) → 写 pending record → safeProviderCall(() => mini.createVideo(req, apiKey))
3
WebView · MiniMaxProvider (web)
POST https://api.minimax.cn/v2/video_generation · buildContent 拼 wire-format · throw / return VideoGenCreateResponse
4
WebView · 回到 useSubmit
拿到 taskId → record 状态 pending → generating → inflightApi.resumePolling(rec)
5
WebView · usePolling
Map<taskId, PollerState> 启动 5s 间隔轮询 → 每 tick 调 mini.queryTask(taskId, apiKey)
6
UXP · 后续飞书上报
任务 succeeded → bridge.downloadFile → UXP 端 downloadCore.downloadToWorkDir → core/ai/providers/minimax/MiniMaxUxPProvider.downloadToWorkDir (fetch + 落盘) → onTerminalSuccess → feishuApi.reportToFeishu(rec) → bridge.reportGenerated → UXP webhookCore.reportGenerated → core/billing.estimateCost → POST 飞书 (含限流退避重试)
